前台实时更新，2026-10-09

App 在 Android 使用现有 Cronet 网络客户端接收 `/api/v1/realtime/events` SSE 事件流，兼容 HTTP/3；其他平台使用原生 WebSocket 连接 `/api/v1/realtime`。两种连接使用同一 API 域名与同一事件协议，通过已有登录请求头向 `/api/v1/realtime/token` 获取短期令牌。令牌新增 `cursor` 字段用于首次连接的水位；首次连接和重新连接都会同步当前状态，之后按收到的游标补收。旧服务未返回水位时兼容从 0 补收。

- 一个账号在当前 App 进程中只有一个前台连接。切后台关闭，回前台恢复；网络故障退避重连，退出登录清空游标，旧连接返回的数据不进入新账号。
- 聊天收件与同账号其他设备发送的消息自动刷新；补收超过一页时获取全部缺口，保留已经加载的历史和编辑中的输入。消息、通知的已读变化同步计数。
- 系统通知刷新与送达确认独立处理，通知确认失败会重试，不阻塞聊天或下线事件。
- 简历导入、导出使用任务事件唤醒并保留定时查询兜底；简历变化刷新简历库，文章审核刷新我的文章，评论与回复刷新打开的文章页，积分和模板购买刷新账号及模板。
- 后台数据库状态变化写入持久事件表，和原业务变更同事务提交；服务器除了 Redis 通知，也每秒检查持久事件表，覆盖独立管理后台和任务进程没有 Redis 通知的情况。所有事件按账号发送，不包含消息正文、简历内容或登录凭证。
- 账号撤销/过期在服务器检查后发送 `SESSION_INVALID`，App 清理登录并显示服务器提供的说明。临时网络失败不等同于注销。

后端补丁 `realtime.patch` 和增量 `realtime-stream.patch` 已应用至 bojian-backend，仅修改实时连接、聊天事件发布、新增 036 迁移和集成测试。发布源码由线上 account-sessions 版本的确切源码复制而来，保留本地另行开发的 gRPC 改动。
