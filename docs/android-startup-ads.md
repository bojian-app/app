# Android 开屏广告

当前仅 Android 接入穿山甲 GroMore 融合 SDK `com.pangle.cn:mediation-sdk:7.8.1.4`，由 `StartupAdsBridge` 桥接 Flutter；不依赖广告分支；发现页 Banner 复用同一 SDK 初始化，不包含激励视频。iOS 后续另行接入。

## 配置与启动行为

- 默认应用 ID：`5898107`；默认开屏广告位：`104711277`。这些 ID 来自已有广告接入资料，应用是否已转正式需在平台核实。
- 可通过 `--dart-define=PANGLE_ANDROID_APP_ID=...` 和 `--dart-define=PANGLE_ANDROID_SPLASH_ID=...` 替换为正式配置。
- 最低 Android API 24；该 SDK 完整原生库仅支持 arm64。其他架构直接跳过广告，不影响应用启动。
- 保留 release 优化，额外保留 SDK 动态调用的公共接口和文件路径资源。广告素材与落地页可能使用 HTTP，已配置对应网络策略；博简业务 API 仍要求 HTTPS。
- 移除了 Android 原生海豚动画和 Flutter 备用海豚动画。系统启动背景仍保留，不人为延长显示。
- 开屏仅在冷启动恢复到已登录状态后请求广告；发现页 Banner 也可在本轮完成登录后初始化广告 SDK；登录页要求同意用户协议与隐私政策。首次未登录、游客及本轮刚完成登录时不弹开屏广告，回到前台也不重播。
- 原生初始化和加载合计最多等待 5 秒，其中广告请求超时 3 秒。失败、无填充或加载期间离开应用直接放行，迟到回调不再展示。
- 展示使用 SDK 自带的广告与跳过控件；关闭后继续进入应用。另设 12 秒展示兜底，防止关闭回调丢失。
- 绑手机提示及共享文件导入在开屏流程结束后继续，避免与广告重叠。
- 关闭定位、电话状态、Wi-Fi 信息、外部存储、Android ID、OAID、录音、应用列表访问及个性化推荐开关；没有免同意初始化的调试后门。

## 人工真机验收

1. 覆盖安装 arm64 包，保留现有账号数据。已登录用户彻底关闭进程再启动，检查旧动画消失、开屏广告及 SDK 跳过按钮。
2. 检查广告关闭后可以正常操作页面；如账号未绑定手机号，确认绑定提示出现在广告关闭后。
3. 断网冷启动，检查等待有限且可继续使用；恢复网络后的广告填充由平台决定。
4. 加载期间返回桌面再回来，确认无迟到广告；广告点击后从落地页返回，确认无覆盖层残留。
5. 退出登录后重启，确认直接到登录页，不初始化广告；登录后发现页可加载 Banner，下一次冷启动才尝试开屏广告。
6. SDK 无填充时读取 `adb logcat -s BojianStartupAds` 的错误码核对应用与广告位配置；编译、安装成功不代表平台已填充或人工验收通过。
