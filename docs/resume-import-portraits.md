# 简历导入头像

关联 [Issue #11](https://github.com/fahnzjan/bojian-mobile/issues/11)。

简历文字识别和头像保存由服务端导入任务处理。DOCX 沿用原有内嵌图片提取；PDF 使用运行镜像已有的 Poppler `pdfimages` 检查第一页图片，提取唯一符合尺寸条件的竖版照片。独立照片会规范化为 PNG，通过现有 `RESUME_PHOTO` 私有存储、任务事务和用户确认流程保存。

PDF 头像提取限制命令耗时、元数据输出、第一页图片总像素、图片数量及单张输出体积。用照片在页面上的显示尺寸排除扫描整页，并跳过横图、方形图标、透明遮罩和多张不同的候选图片；相同照片重复出现只保留一张。此流程不裁剪扫描整页中的人像，无法明确识别的情况可由用户手动添加照片。可选 PDF 头像提取失败保留已识别的文字；取消导入继续遵守原有任务取消和事务清理逻辑。

简历照片与账号头像分别保存：`RESUME_PHOTO` 继续使用私有空间签名下载，公开 CDN 只承载账号头像。当前存储规则见[App 文件访问](file-storage.md)。

对修复前已经导入且缺少照片的记录，维护操作先备份数据库，核对原文件归属和摘要；上传并验证图片可读后，再以事务更新缺失的照片引用。已有照片、正在变化的记录和来源不一致的文件不覆盖。已保存简历仅更新照片、版本及更新时间，正文保持；待确认任务仅补内部照片字段，继续由用户确认保存。

2026-10-18 已发布服务端修复，并补回本次已保存简历及待确认导入记录的缺失照片。真实原文件提取前后的像素一致，照片私有签名下载返回 200，正文、账号头像和管理员保留。客户端返回简历列表后重新打开已保存简历即可获取新照片地址，无需重新安装。
