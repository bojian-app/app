# 简历总览与分区编辑

按用户提供的 WPS 截图组织编辑流程：总览展示内容卡片，点击卡片进入对应的独立编辑页。

- 总览：紧凑完整度、左侧姓名/电话/邮箱与右侧照片、求职意向、自我评价及工作/项目/教育/技能/证书内容。空分区显示填写入口。
- 分区页：仅展示该分区表单，基本信息页顶部单独放置照片，更多个人信息可展开；照片选择裁剪、日期弹窗及经历增删排序在对应页面操作。
- 照片操作：点击基本信息页的头像行，打开“编辑照片”底部面板；已有照片时显示“删除照片”“修改照片”，空照片时提供“添加照片”。修改/添加进入系统照片选择器，关闭面板不更改照片。照片行不常驻更换/移除按钮。
- 分区保存：校验本页字段，返回总览并保留修改，提示“已更新，保存简历后生效”。
- 分区返回：撤销本次未保存的文字、选择项、条目增删排序及照片修改；进入前已保存到总览的修改保留。
- 总览保存：向服务端提交整份简历与照片。缺少姓名、简历名称或意向职位时，打开对应分区显示字段校验；提交失败后仍可继续修改和重试。

状态由 `ResumeEditor` 持有；`ResumeOverviewCard`/`ResumeOverviewEntry` 负责卡片展示，`ResumeSectionEditorPage` 负责页面与本页表单校验。分区返回后再恢复控制器，避免在退出动画中释放仍被使用的控制器。照片保留进入分区前的裁剪文件，在分区确认或撤销时清理被替代的临时文件。

字号沿用 [字号约定](resume-editor-typography.md)，保留深浅主题与系统文字缩放；独立编辑页在短屏键盘场景使用顶栏保存。
