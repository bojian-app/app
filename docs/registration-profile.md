# 首次注册的微信／抖音资料

关联：[Issue #10](https://github.com/fahnzjan/bojian-mobile/issues/10)。

移动微信和抖音登录在服务端验证一次性授权码后，仅对尚未注册的身份调用官方用户资料接口，校验返回的 OpenID 与此次授权一致。昵称清理控制字符并限制为现有资料字段的 80 个字符；头像只接受所属平台的 CDN 地址。

资料保存在五分钟有效、加密且绑定设备的注册确认凭证中。客户端不能提交昵称、头像或平台令牌来替代这次校验。用户取消注册时不创建用户或上传头像；确认注册后，在同一个事务内初始化昵称及头像文件记录。头像经过 HTTPS、域名／地址校验、大小及像素限制、图片解码后保存到博简现有头像存储，使用原有个人资料接口展示。

仅在新账号创建分支写入，之后登录或另一个未消费的注册凭证不会覆盖在博简修改过的昵称和头像。平台资料或头像获取失败时返回可重试的资料同步错误，回滚未完成注册；上传成功但事务失败时清理对应对象。平台令牌、私有凭证及原始上游错误不返回 App。

头像验收还需验证返回的下载链接：文件记录为 READY 不代表客户端一定可以读取。2026-10-18 首次排查时，微信和抖音头像均已保存，但下载 CDN 连接中断，因此临时使用七牛 SDK 查询并验证内容摘要的 HTTPS 源站。

随后按用户要求试用 `https://cdn.kelance.cn`，两个现有平台头像通过该 CDN 的签名链接返回 200，大小和 SHA-256 与保存记录一致。用户进一步选择将 CDN 用于独立公开头像空间，私有文件使用源站签名链接；最终配置与迁移流程见[App 文件访问](file-storage.md)。头像返回固定、无临时签名的 CDN 地址，客户端刷新接口后获取，无需重新安装。

七牛源站下载必须签名，且有效期最长五分钟，见[官方 Go SDK 说明](https://developer-doc.qiniu.com/products/kodo/go)。存储层为 `.qiniucs.com` 源站生成下载链接时限制该有效期；更短的配置继续使用原值。此限制仅作用于下载，上传令牌继续使用配置有效期。现有账号直接读取已保存头像，无需重新注册或覆盖用户资料。

真实平台返回仍需测试者在微信／抖音中完成授权，自动测试使用官方响应格式和隔离数据库，不代替用户授权。

官方接口：[微信用户信息](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/WeChat_Login/Authorized_API_call_UnionID.html)、[抖音用户公开信息](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/account-permission/get-account-open-info)。
