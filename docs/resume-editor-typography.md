# 简历编辑页字号约定

来源：用户指定的 [iOS&Android 移动设计字体规范整理大全](https://blog.csdn.net/weixin_30511107/article/details/97898971)，参考其中 Android 表格的 12、14、18、22 字号档位。以下角色分配结合用户提供的 WPS 总览与独立编辑页截图，是本项目的落地映射。

| 编辑页角色 | 字号 | 应用位置 |
| --- | --- | --- |
| 页面与分区标题 | 18 | 创建/编辑简历、总览姓名、基本信息及其他分区 |
| 正文与输入内容 | 14 | 总览正文、所有表单值（包括姓名）、占位文字、下拉选项、在职状态 |
| 操作与状态 | 14 | 保存、添加经历、更多基本信息、照片操作、总览完整度标题与百分比 |
| 辅助信息 | 12 | 字段标签、完整度说明、条目摘要、日期、保存状态、错误提示 |

样式集中在 `lib/resume_editor_typography.dart`。总览姓名作为名片标题，独立编辑页中的姓名与其他输入内容保持相同字号；正文和占位文字字号一致。沿用 App 系统字体，使用 Flutter 逻辑单位并保留系统文字缩放。

范围为简历总览与全部八个独立编辑页，交互见 [编辑流程](resume-editor-flow.md)。照片选择器、日期弹层、确认对话框和简历预览/导出沿用各自样式。
