# App 文件访问

关联 [Issue #10](https://github.com/fahnzjan/bojian-mobile/issues/10)。

头像使用独立公开空间 `bojian-public-avatars`，下载域名为 `https://cdn.kelance.cn`。同一个头像对象返回固定地址，不带 `e`、`token` 等临时签名参数；更换头像时生成新对象键，因此使用新地址。文件被主动删除后，固定地址也可能失效；固定地址不代表承诺保留已删除内容。

简历、导出文件、证明材料等保存在新私有空间 `bojian-private`，由后端生成七牛 HTTPS 源站的临时签名链接。源站下载最长五分钟，上传凭证继续使用原配置有效期。管理后台读取私有证明材料同样遵守源站签名时效。

服务端配置：

| 配置 | 用途 |
| --- | --- |
| `QINIU_BUCKET` | 私有业务文件空间 |
| `QINIU_DOMAIN` | 私有空间 HTTPS 源站 |
| `QINIU_PUBLIC_AVATAR_BUCKET` | 独立公开头像空间 |
| `QINIU_PUBLIC_AVATAR_DOMAIN` | 公开头像 CDN 的 HTTPS 域名 |

两个公开头像配置需同时填写，且不能与私有空间同名。头像专用对象前缀为 `public/avatars/`；私有文件前缀不得与它重叠。上传、读取、删除和异步对象清理都通过同一存储层分流。客户端从接口读取 URL，不在页面中替换域名或保存平台的原始头像链接。

现有头像迁移先复制并核验大小及 SHA-256。CDN 改绑期间临时限制访问，完成 HTTP 与 HTTPS 根目录旧缓存刷新后，恢复原访问规则并验证无签名下载。最后事务更新头像文件记录的对象键，不创建账号或覆盖昵称。

用户随后要求替换旧私有空间。检查时旧 `bojian-pc` 已返回不存在（612），本轮没有执行它的删除操作；已创建并核验新的 `bojian-private` 为华南私有空间。切换前核查有效或待上传的非头像私有文件引用为零；两个现有头像副本完整，文件记录已切换，下载返回 200 且 SHA-256 一致。账号、昵称和管理员保留。此前测试清理及版本发布的私有备份保留在服务器。
