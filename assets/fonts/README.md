ResumeDocument, applied-template previews, template marketplace previews, and PDF/Word exports use unmodified Alibaba PuHuiTi 3.0 (font version 3.01). Flutter, HTML, PDF and Word use the real Regular, Medium (500/600), and Bold faces. Word references the fonts by their legacy family names `阿里巴巴普惠体 3.0 55 Regular` (regular/bold) and `阿里巴巴普惠体 3.0 65 Medium`, matching the embedded files; PDF embeds used glyph subsets. Word readers that ignore embedded fonts can substitute their own fonts; the document includes no-wrap text boxes with room to avoid clipping. Flutter interface typography is unchanged.

The original files come from the official https://www.alibabafonts.com/ site. The complete official legal notice is bundled in `AlibabaPuHuiTi-LICENSE.txt`, sourced from https://www.yuque.com/yiguang-wkqc2/hgpff0/nus9wiinq4aeiegy. Font binaries are not converted or subsetted before packaging.
